// THE SYSTEM

One place for every ICT assessment.

ICT Ground hosts every Computer Science assessment for Year 10 and 11 (IGCSE) — auto-marked on submission, with results and marked papers collected in one dashboard for staff.

01 // AUTO-MARK

Instant grading

Every test is marked the moment a student submits — no manual marking, no delay.

02 // OFFLINE-SAFE

Works without WiFi

Answers are saved on-device as students work, so a dropped connection never loses a result.

03 // CENTRALISED

One results dashboard

Every submission, score and marked paper lands in a single staff-only panel — sortable, searchable, exportable.
